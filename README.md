# 装窑排位

免构建的本地网页，用于装窑前摆位、温度/釉料风险检查、锁炉补件、开炉结算和坏损复盘。

## 使用

直接用浏览器打开 `index.html`。数据保存在当前浏览器的 `localStorage`，不需要服务端。

## 功能

- 待烧坯体登记名称、窑主、目标温度和是否滴釉。
- 窑位图按层和号位展示；待烧清单可手动选位，也可自动排位。
- 摆不下的坯体留在待烧清单，并显示窑位已满、同窑温差超限等原因。
- 同窑温差超过红线会阻断锁炉；近位温差过大、滴釉层位不对会当场标为提醒。
- 滴釉坯应放在设定的下层；放到上层或上层已有坯体时会提示。
- 按窑主统计已占位、待烧、合计和温度区间；开炉后按件归档结果。
- 锁炉后不能挪动或删除已入窑坯体；后来的人只能选择剩余空位，加入前强制整窑复核。
- 开炉时记录完好、瑕疵、烧坏、所在层位和原因；历史坏损层位会在下次装窑时提示。

## 文件

- `index.html`：页面结构
- `styles.css`：页面样式
- `app.js`：窑位、风险、锁定、结算和历史记录逻辑
