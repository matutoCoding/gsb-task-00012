# 装窑排器

窑场装窑用的单页工具：把**待烧坯体、各人的温度要求、窑里每层每个位置**摆到一个页面上，
温度、釉滴、位置三样一起校验，少烧一窑冤枉窑。纯前端，数据存在本机浏览器，双击 `index.html` 即可离线使用。

## 怎么用

1. 打开 `index.html`（任意现代浏览器，无需联网、无需安装）。
2. 「＋ 登记坯体」：名称、主人、要求温度；大件选「占双格」；釉会滴的勾上「釉料会滴」。
3. 「＋ 新窑炉」：设层数、每层格位数、本炉柴火费（选填）。
4. 装窑：在左边点选一件坯（高亮可选），再点窑里的空格；也支持拖拽。
   - 放得进 → 直接入位；放不进 → 当场说明原因。
   - 往**已锁定**的窑加件，会弹出「锁窑复评」，整窑风险重新过一遍才能确认。
5. 炉子定下来后点「锁住此炉」：后来的人只能动剩下的位置，锁前有冲突不能锁、有黄警要确认。
6. 烧完点「出窑登记」：逐件记好坏，烧坏的写清坏在哪层、什么毛病，自动归档并清空此窑。
7. 「烧窑记录」页可按窑号/主人/坯体搜索，看坏件集中在哪层，导出 CSV。

## 校验规则

- **同窑温差（红，硬冲突）**：一炉里最高温与最低温差超过阈值（默认 40℃）不能同窑，两端件标红。
- **同层相邻温差（黄，风险）**：贴邻两件温差超过阈值（默认 20℃）双方标黄；隔空格不算贴邻。
- **釉滴件**：勾了「釉料会滴」的只能放最底层，放错层直接标红。
- **占位**：大件占连续两格，没有连续空位则摆不下。
- 阈值可在右上角「阈值设置」里改，按本窑实际情况调。

## 分账

每座窑按各人**实际占格数**分摊柴火费（双格件算 2 格），尾差补给占格最多的人；
烧窑记录里还会按件数再算一次出窑分摊，均支持 CSV 导出对账。

## 文件

- `index.html` / `styles.css` / `app.js`：应用本体，无构建、无依赖。
- `tests/logic.test.js`、`tests/render.test.js`：核心规则与渲染的 Node 冒烟测试
  （`node tests/logic.test.js`，无需安装依赖）。
- 数据保存在浏览器 `localStorage`；「阈值设置 → 清空全部数据」可恢复内置示例。
